\textit{2. Performance on Vulnerable Pedestrian.}
Continuous spatial offsets and decoupled heads deliver pronounced performance gains on vulnerable road users. Sparse returns and aspect-ratio differences make small, non-rigid objects such as pedestrians difficult to detect. Table~\ref{tab:comparison} and Figure~\ref{fig:pr_curves} report MobilePIXORNeXt's \textbf{60.75\% Moderate AP} on Pedestrians. Two mechanisms explain this advantage: Strata-BEV14's continuous subcell displacement offsets $(\Delta\bar{x}, \Delta\bar{y})$, which reduce quantization error from the $0.1\,\text{m}$ grid for small objects, and GroupedHeader, which separates pedestrian regression from vehicle footprints to eliminate inter-class gradient interference.

\paragraph{Pipeline Latency vs. Model Forward Throughput.}
Network forward time covers only part of a real-time perception pipeline. Full-system latency includes point cloud loading, tensorization, Host-to-Device (H2D) transfer, network execution, coordinate decoding, and Non-Maximum Suppression (NMS). Table~\ref{tab:efficiency} reports sequential latency at batch size 1 over $3{,}759$ timed frames, excluding 10 warmup frames from the $3{,}769$-frame validation split. All detectors, including MobilePIXOR and reference networks, are evaluated under identical conditions on the same NVIDIA Tesla T4 GPU.



\textit{1. End-to-End Pipeline Latency Comparison.}
Table~\ref{tab:efficiency} reports MobilePIXORNeXt's End-to-End (E2E) latency of \textbf{60.96\,ms} (\textbf{16.41\,FPS}), the lowest among the evaluated real-time detectors. MobilePIXORNeXt ran faster than PointPillars ($63.84\,\text{ms}$, $15.66\,\text{FPS}$), MobilePIXOR ($90.65\,\text{ms}$, $11.03\,\text{FPS}$), and SECOND ($93.70\,\text{ms}$, $10.67\,\text{FPS}$). It also ran over $2.3\times$ faster than PIXOR ($144.00\,\text{ms}$, $6.94\,\text{FPS}$). Percentile analysis showed low latency dispersion in the evaluated desktop GPU environment: median P50 latency was \textbf{58.28\,ms}, P95 was $80.85\,\text{ms}$, and P99 was $95.91\,\text{ms}$.

\textit{2. Component Latency Profiling and Host-to-Device Efficiency.}
Stage-level profiling identified the following sources of the throughput advantage:
\begin{itemize}
    \item \textbf{Input Preprocessing ($20.94\,\text{ms}$)}: Point-cloud file loading and Strata-BEV14 rasterization with the Numba CPU backend took $20.94\,\text{ms}$. The implementation uses occupied-cell accumulators and precomputed logarithmic lookup tables. Recorded preprocessing took $27.75\,\text{ms}$ for PointPillars and $27.20\,\text{ms}$ for SECOND. These measurements cover complete input preparation.
    \item \textbf{Host-to-Device Memory Transfer ($6.91\,\text{ms}$)}: Binary occupancy tensors with a 35-channel layout require $78.8\,\text{MB}$ per scan. The Strata-BEV14 14-channel layout required $31.5\,\text{MB}$, reducing tensor memory payload by $60.0\%$. Recorded H2D transfer time on Tesla T4 with pinned-memory buffers was $6.91\,\text{ms}$ for Strata-BEV14 ($31.5\,\text{MB}$), compared with $43.45\,\text{ms}$ for MobilePIXOR's unpinned 35-channel representation ($78.8\,\text{MB}$) on the same platform, directly reflecting the $60.0\%$ reduction in memory payload.
    \item \textbf{Model Forward Propagation ($17.88\,\text{ms}$)}: Network inference took $17.88\,\text{ms}$ ($55.94\,\text{FPS}$) on Tesla T4, outperforming MobilePIXOR's forward inference ($25.43\,\text{ms}$, $39.32\,\text{FPS}$) on the same hardware. Optimized standalone inference reached \textbf{115.32\,FPS} ($8.67\,\text{ms}$).
    \item \textbf{Decoding and Rotated NMS ($14.94\,\text{ms}$)}: Candidate peak selection and class-wise rotated NMS took $14.94\,\text{ms}$. Data remained on the GPU until final bounding box export.
\end{itemize}

\subsection{Ablation Studies}
\label{sec:ablations}

\paragraph{Systematic Architectural Progression.}
To quantify the individual and cumulative contributions of the proposed components, Table~\ref{tab:components} details the step-by-step ablation progression from the baseline to the final configuration.

\paragraph{1. Backbone Architecture (A0 $\to$ A1).}
Replacing MobilePIXOR's residual blocks with a ConvNeXt-style backbone using $7 \times 7$ depthwise convolutions, inverted expansion $e=2.5$, SiLU, and LayerScale raised Moderate mAP from $41.40\%$ to $47.60\%$ (\textbf{+6.20\,pp Moderate mAP}), while standalone throughput nearly doubled from $90.57$ to \textbf{169.97\,FPS}. Large depthwise kernels broaden BEV receptive fields with limited computational cost.

\paragraph{2. BEV Input Representation (A1 $\to$ A2 $\to$ A3).}
\input{tables/encoding}
To assess how input rasterization affects detection accuracy and latency, Table~\ref{tab:encoding} compares four distinct BEV representations under identical MobilePIXORNeXt backbone and single-head architecture. TriBand-BEV~\cite{khoshkdahan2026triband} partitions points into three coarse height bands; while it delivers the highest inference throughput ($188.4\,\text{FPS}$) and lowest Host-to-Device transfer payload ($6.76\,\text{MB}$), its Moderate mAP drops to $44.42\%$ ($-5.72\,\text{pp}$ below Strata-BEV14). The lack of continuous elevation moments and horizontal subcell centroid offsets degrades small object localization (Pedestrian AP $38.05\%$, Cyclist AP $21.12\%$). Conventional 35-channel binary occupancy slicing (A1) achieves $47.60\%$ mAP but requires transferring $78.85\,\text{MB}$ per scan, imposing significant Host-to-Device transfer latency ($40.63\,\text{ms}$) while still discarding sub-voxel point coordinates. The 8-channel Strata-BEV8 representation (A2) yields comparable accuracy ($47.37\%$) with fewer channels. In contrast, our 14-channel Strata-BEV14 representation (A3) achieves the highest Moderate mAP of $50.14\%$ ($+5.72\,\text{pp}$ over TriBand-BEV and $+2.54\,\text{pp}$ over Binary35) at $169.0\,\text{FPS}$. Continuous vertical spatial moments ($z_{\max}, z_{\mathrm{mean}}, z_{\mathrm{span}}, z_{\mathrm{std}}$) and subcell centroid displacement offsets $(\Delta\bar{x}, \Delta\bar{y})$ retain critical 3D geometry otherwise lost through horizontal discretization without incurring PointNet encoder overhead.

\paragraph{3. Decoupled Grouped Prediction Towers (A3 $\to$ A4 $\to$ A5).}
Separating Car and Ped/Cyc prediction heads (A4) raised Moderate mAP to $51.30\%$ ($+1.16\,\text{pp}$ over A3). Increasing grouped head width from 16 to 32 channels (A5) raised Moderate mAP to $60.22\%$ (\textbf{+8.92\,pp Moderate mAP}) and $\text{mAP}_9$ to $61.11\%$ relative to configuration A4 (a combined $+10.08\,\text{pp}$ gain over A3). In configuration A4, compressing shared intermediate features into only 16 channels induces severe subspace rank collapse when the convolutional tower attempts to project four distinct regression targets (offset, log-size, doubled-angle yaw, and quality) across heterogeneous object scales. Expanding head width to 32 channels (A5) adds only $75\,\text{K}$ parameters but doubles the latent representation rank. This additional subspace capacity provides sufficient degrees of freedom to decouple inter-task gradients between orthogonal geometric properties, driving an $+8.92\,\text{pp}$ jump ($+10.08\,\text{pp}$ over baseline A3).

\paragraph{4. Physics-Consistent Ground-Truth Augmentation (A5 $\to$ A6).}
Physics-consistent augmentation (\texttt{PC-GTA}) improved Moderate mAP by \textbf{+6.03\,pp} over A5, from $60.22\%$ to $66.25\%$. It also raised $\text{mAP}_9$ from $61.11\%$ to $68.45\%$ (\textbf{+7.34\,pp $\text{mAP}_9$}). The evaluated sampler combined terrain alignment, static obstacle rejection, and range-dependent point subsampling. Optional LOS, shadow-masking, and radiometric mechanisms were disabled in the final run.

\paragraph{5. Multiscale Neck and Scale Gating (A6 $\to$ A7 $\to$ A8).}
Increasing neck width from 24 to 32 channels (A7) raised Moderate mAP to $68.12\%$ (\textbf{+1.87\,pp Moderate mAP}). The Top-Down Scale-Gated FPN (A8) replaced transposed convolutions with bilinear upsampling and learnable depthwise gating to avoid deconvolution checkerboard artifacts in continuous regression maps. Under standard unweighted Smooth-L1 coordinate regression, this depthwise gating causes a slight drop from $68.12\%$ to $67.38\%$ ($-0.74\,\text{pp}$), as multiplicative gating without explicit geometric loss coupling tends to attenuate weak gradient signals from distant and sparse point returns.

\paragraph{6. Geometric Supervision and Localization Quality (A8 $\to$ A9).}
Oriented Geometric Alignment (OGA) and IoU-Aware Quality Alignment (IQA) raised Moderate mAP from $67.38\%$ to $70.58\%$ (\textbf{+3.20\,pp Moderate mAP}). This $+3.20\,\text{pp}$ surge reveals a decisive co-design synergy: while SG-FPN alone slightly attenuates weak returns under Smooth-L1, it provides the precise multi-scale spatial separation that OGA and IQA require. Multi-Axis Projection GIoU and scale-normalized $\pi$-symmetric corner distances provide direct, rotation-aware gradient feedback across the scale-gated features, while IQA calibrates classification confidence against continuous bounding box overlap to eliminate the suppression of accurate candidates by poorly aligned boxes during rotated NMS.

\paragraph{7. Block-SimAM Energy Attention (A9 $\to$ A10).}
Embedding parameter-free Block-SimAM in every residual block across stages C2, C3, and C4 produced the final configuration, reaching \textbf{71.46\% Moderate mAP} and \textbf{73.42\% mAP$_9$} (\textbf{+0.88\,pp Moderate mAP}).
Compared with the no-attention configuration, block-level SimAM raised Moderate mAP by 0.88 percentage points and $\text{mAP}_9$ by 0.76 points, with a minimal $0.48\,\text{ms}$ increase in standalone forward latency. The final configuration also combined OGA and IQA; the following factorial study isolates each component's contribution.
Block-SimAM gained 1.66--2.10\,pp in Moderate mAP over stage-level variants at 115.32 standalone FPS (versus 144.05\,FPS for Stage-3 SimAM).


\paragraph{Geometric Supervision and Quality Head Factorial Study.}
Table~\ref{tab:loss} presents a $2 \times 2$ factorial evaluation isolating the effects of OGA geometric supervision and the explicit IQA prediction branch.

IQA alone raised mAP to $70.31\%$ (\textbf{+2.93\,pp Moderate mAP}). Together, OGA and IQA achieved \textbf{70.58\% Moderate mAP}, with the highest Car ($84.87\%$) and Pedestrian ($59.63\%$) scores. \paragraph{Multi-Task Optimization Dynamics and Convergence.}
Figure~\ref{fig:loss_curves} plots training and validation losses over 50 epochs for configurations A1 through A10. It includes the total objective and six tasks: Classification, Geometry, IoU Quality, Subcell Offset, Size, and Yaw. We used these trajectories to assess training stability and convergence.
Across 50 epochs, total and task losses exhibited steady downward convergence trends. Total loss fell from $10^4$ to approximately $1.0$ within the first 15 epochs, progressing stably through cosine annealing. While transient validation classification spikes were observed between epochs 18 and 25 (briefly reaching $\sim 10^2$ before dampening), the training and validation regression curves remained well-bounded without unbounded divergence. This trend reflects the stabilizing effect of physics-consistent data augmentation (PC-GTA, A6) and loss balancing.
Temperature-Softmax Bounded Uncertainty Weighting (T-SBUW, Eq.~(\ref{eq:tsbuw_weights})--(\ref{eq:balanced_loss})) dynamically bounded task gradient magnitudes, mitigating gradient competition between cross-entropy classification and coordinate regression. Configuration A10 achieved low, stable late-training validation losses across regression tasks, aligning with the empirical evaluation in Table~\ref{tab:components}.

\paragraph{Training Schedule Fairness and Convergence Validation.}
To confirm that MobilePIXORNeXt's competitive detection accuracy is not an artifact of an extended 160-epoch schedule compared to standard 50-epoch baselines, we evaluate the minimum validation loss checkpoint within the standard 50-epoch regime (Epoch~47) against the AP-selected checkpoint from the extended run (Epoch~130). Under identical KITTI $R_{40}$ Moderate evaluation, the 50-epoch checkpoint already attained $71.48\%$ Moderate mAP ($82.71\%$ Car, $62.30\%$ Pedestrian, $69.43\%$ Cyclist, and $73.57\%$ $\text{mAP}_9$), matching and slightly surpassing the 160-epoch checkpoint ($71.46\%$ Moderate mAP: $86.90\%$ Car, $60.75\%$ Pedestrian, $66.73\%$ Cyclist). This empirical comparison confirms that MobilePIXORNeXt's detection performance is fully consolidated within 50 epochs, ensuring a fair protocol comparison against standard baselines. The primary benefit of the extended 160-epoch schedule is not artificial accuracy inflation, but rather the progressive sharpening of foreground classification heatmaps and suppression of low-confidence background false positives. This sharpening reduces the number of candidate boxes evaluated during peak extraction and rotated NMS, slashing end-to-end latency by $25.0\%$ ($81.23\,\text{ms} \to 60.96\,\text{ms}$, or $12.31 \to 16.41\,\text{FPS}$).

\subsection{Discussion and Practical Limitations}
\label{sec:discussion_limitations}

\paragraph{Discussion and Insights.}
The results showed that accurate 3D LiDAR detection was possible without large point-cloud encoders or 3D sparse convolutions. The deterministic 2D BEV representation retained multi-band densities, elevation dispersion, and continuous subcell centroid displacements. A ConvNeXt-style 2D network extracted geometric features with fewer than $0.76\,\text{M}$ parameters. Physics-consistent augmentation (\texttt{PC-GTA}) and decoupled grouped heads provided the most substantial individual accuracy improvements in the architectural progression, demonstrating the value of domain-specific LiDAR data modeling and multi-class gradient isolation.

\paragraph{Limitations and Future Scope.}
MobilePIXORNeXt is optimized for oriented 2D Bird's-Eye View footprint detection on the $SE(2)$ manifold, directly addressing horizontal clearance and Time-to-Collision (TTC) requirements for vehicular collision avoidance. While an auxiliary vertical regression branch supports 3D bounding box estimation ($z, h$), several physical boundaries remain. First, our empirical validation relies on 64-beam mechanical spinning LiDAR on predominantly planar urban roadways. Although Strata-BEV14's continuous elevation moments ($z_{\mathrm{span}}, z_{\mathrm{std}}$) and log-density normalization maintain numerical stability under point sparsity, performance on ultra-sparse 16-beam or non-repetitive solid-state LiDAR sensors warrants systematic domain investigation. Second, on severe terrain slopes or multi-level grade transitions, planar BEV projections introduce perspective distortion along vertical structural boundaries. Future work will address these constraints by developing Range-Conditioned Scale-Gated Feature Pyramids (RC-SGFPN) with continuous spatial frequency modulation, and deploying hardware-tailored TensorRT INT8 quantization for low-power edge microcontrollers.
