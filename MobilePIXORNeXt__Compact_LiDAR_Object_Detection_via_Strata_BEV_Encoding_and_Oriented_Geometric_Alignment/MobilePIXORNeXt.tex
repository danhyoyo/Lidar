\begin{abstract}
Accurate 3D object perception from Light Detection and Ranging (LiDAR) point clouds is an important challenge for autonomous vehicles, where volumetric and pillar networks frequently exceed edge computational budgets. In this paper, we present MobilePIXORNeXt, an ultra-compact, proposal-free detector targeting oriented bounding footprints on the Special Euclidean (SE) manifold $SE(2)$ for real-time collision avoidance and path planning. With 753,569 trainable parameters, the framework replaces heavy learned point encoders with Strata-BEV14, a deterministic Central Processing Unit (CPU) statistical rasterizer computing 14 feature channels in 20.94 milliseconds. A single-branch ConvNeXt-style backbone with parameter-free 3D spatial-energy attention (Block-SimAM) extracts multi-scale features, while a Scale-Gated Feature Pyramid Network fuses representations for decoupled grouped prediction heads. The model is trained using Physics-Consistent Ground-Truth Augmentation and Oriented Geometric Alignment (OGA), balanced by 12-parameter Temperature-Softmax Bounded Uncertainty Weighting. On the KITTI benchmark under 40-point interpolated Average Precision (AP), MobilePIXORNeXt achieves 71.46\% Moderate mean Average Precision (mAP) and 73.42\% overall 9-cell mAP across Car, Pedestrian, and Cyclist. It exceeds PointPillars by 1.33 percentage points with an 84.41\% parameter reduction and trails SECOND by only 0.63 percentage points with 85.85\% fewer parameters, while pedestrian Moderate AP reaches 60.75\%. We also examine Q-OGA as a head-free variant achieving 69.20\% Moderate mAP. On an NVIDIA (NVIDIA) Tesla T4 GPU, the end-to-end pipeline operates in 60.96 milliseconds (16.41 frames per second). These results demonstrate that deterministic statistical encoding coupled with oriented geometric alignment enables accurate, real-time perception on edge vehicular platforms.
\end{abstract}
