### Risks & mitigations
- Pending edits and redraws can interact: use form snapshots, native validation, atomic commands and dedicated regression checks.
- Mobile drawers can obscure keyboard focus: manage focus, Escape and inert background; test real touch events and narrow widths.
- Existing documents must remain compatible: preserve schema and source artifacts; test imports, undo and export.
