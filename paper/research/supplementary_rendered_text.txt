S1 Representation and architecture details
Table S1 specifies Hist14. Points must be finite in their first four fields, with the encoder using open ROI boundaries
and an exclusion of 10−3 m. Bins assign a point on an interior height boundary to the upper bin. Accumulation
and coordinate arithmetic use float64; the output tensor uses float32. The stored layout is YXC and the model
layout is BCYX. The full spatial shape is 800 × 704, independent of the number of input points.

OGA’s adaptive pool contains classification, center, size, yaw, and geometric loss, with a sixth task when IQA
is enabled. Each group has independent adaptive state. Its weights sum to the number of pooled tasks. This
constraint bounds relative weights before running-scale normalization and does not fix the total gradient norm.
Final3D adds masked Smooth-L1 on (zb, log h) after the BEV objective, with coefficient one; the vertical term is
not adaptively weighted.
P11 uses the saved Q-OGA configuration: projection-based quality, no separate IQA, quality-focal exponent
one, soft corner assignment temperature 0.05, and range parameters αr = 2, γr = 1.5, and rmax = 70.4 m.
Coordinate Smooth-L1 terms are multiplied by range weights. This configuration does not use the later opt-in
exact rotated-IoU target or a quality curriculum. Consequently, P11 should not be described as an exact-IoU
quality experiment. Q-OGA is an implementation comparison influenced by quality focal learning [3], with several
simultaneous objective changes.

S3 Evaluation and evidence provenance
KITTI [5] training and validation manifests contain 3,712 and 3,769 unique frame IDs with no frame overlap. The
validation file SHA-256 is 2f76fc0f69b5d9786f008694274baaa49d878ba076b96529c488939fd83564c0. The main
ablations use the local loader-aligned BEV R40 implementation. This metric restricts original labels to the loader
center crop and applies its difficulty and neighboring-class ignore rules. It is not substituted for full-frame reference
AP. Detection score threshold is 0.05, suppression threshold is 0.1, and the global cap is 500 after classwise BEV
suppression. With IQA, the scoring exponent is 0.5.
The reference source is OpenPCDet revision 233f849829b6ac19afb8af8837a0246890908755, directory pcdet/
datasets/kitti/kitti_object_eval_python [6]. The saved report verifies unchanged evaluator and overlap
sources and real compatible Numba CUDA execution. It retains metric-specific neighboring-class and DontCare be￾havior. Predictions use all eight camera-coordinate corners, clipping cuboid edges at camera depth 0.1 m before clip￾ping the projected rectangle to the actual image. The orientation representation is π-symmetric, so AOS is disabled.
The epoch-70 checkpoint SHA-256 is 1d0e0cd11c27229942e31a3424c905e896f29d52f2f209481ac8eeb60088ff55.
The Final3D config digest is 404fbd003caadb2e98a876ff993a31e01822d6226e9f3c4d6cf8351d4127e036. Exact
source digests and full reports are supplied in the research directory.
Recovery of training-time configurations
All 21 supplied BEV configuration files contain a post-run header_architecture=shared field. Their hashes
therefore differ from the training-time config hashes in run.json. Removing this single field and serializing with
the original formatting reproduces every recorded training hash exactly. Serialized checkpoint parameter names
show independent branch convolutions, consistent with the saved parameter counts and the original omitted-key
behavior. The manuscript package preserves the unmodified supplied configs in research/configs/as_provided/,
the recovered training configs in research/configs/, and an audit of hashes and checkpoint parameter names in
configuration_audit.json. No source experiment file is changed. Final3D explicitly uses shared heads and its
supplied config already matches the training digest.
Scope of the assembled evidence
The manuscript preparation reads 21 run directories and 41 saved BEV evaluation reports, together with the
separately supplied Final3D evaluations and CPU diagnostic. It performs no new detector training, inference, or
benchmark execution. Numeric AP and parameter values are checked against raw JSON, which takes precedence
over spreadsheet cells that have been interpreted as dates. The paper’s figures are either supplied images/vector
diagrams or plots computed from these saved values. The complete editable 25-slide PowerPoint is preserved. Slide
21 and its supplied vector counterpart match the P16 BEV architecture; early illustrative slides contain inconsistent
labels and are not used as the authoritative model specification.
S4 Full ablations, operating points, and checkpoint selection
Table S2 defines the manuscript run labels. B0 and B1 are historical loss-selected runs with unequal budgets.
The remaining 19 runs complete 50 epochs and use AP-based selection. P1–P4 hold the central architecture and
training recipe fixed while changing the objective and quality head. P4/P14/P15/P16 change the local refinement
module. Earlier comparisons have additional configuration or source differences; Table S5 states the appropriate
interpretation. The originally supplied operating-point CSV uses label B0 for the later S32 baseline; the manuscript
consistently reserves B0 for historical MobilePIXOR.
The shared-versus-independent worksheet includes prospective architectural parameter re-counts. Those rows
do not imply trained accuracy or measured speed for every proposed head. Final3D supplies one actually trained
shared-head configuration. Its detector count excludes twelve train-only criterion parameters. The recorded per￾group head counts are 65,290 for Car and 65,323 for Pedestrian/Cyclist.

S5 Qualitative artifacts and conditional vertical analysis
The supplied demonstration checkpoint is P4, selected at epoch 50. Frame 004338 belongs to validation and frame
005663 to training. The augmented pipeline example uses frame 005663, random seed two, and 17 inserted ground￾truth objects drawn from training donors. It illustrates data processing rather than detector accuracy on an unseen
frame. Feature maps depict root-mean-square activations, classification maps show sigmoid scores, and Gaussian
supervision maps show targets; they are distinct quantities.

vertical extent is estimated from points rather than predicted by Final3D. The panels are a pipeline illustration,
not an AP experiment.

10-frame/s playback rate yields a 17.4-second clip and is not a measured inference rate. The contact sheet in Fig. S5
provides temporal examples without establishing tracking accuracy.
The existing CPU geometric diagnostic uses the same epoch-70 checkpoint digest as the GPU reference eval￾uation and verifies 3,769 scan, label, and calibration inputs against stored hashes. It obtains 107,194 projected
detections, compared with 107,073 in the saved GPU report. Associations are fixed before oracle substitution and
omit metric-specific ignored neighbors and DontCare treatment. Therefore, conditional pass fractions, objectwise
errors, and reference AP remain distinct measurements.
