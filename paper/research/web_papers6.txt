Title: FastPillars: A Deployment-friendly Pillar-based 3D Detector
Authors: Sifan Zhou, Zhi Tian, Xiangxiang Chu, Xinyu Zhang, Bo Zhang, Xiaobo Lu, Chengjian Feng, Zequn Jie, Patrick Yin Chiang, Lin Ma
Date: Sun Feb  5 12:13:27 2023

The deployment of 3D detectors strikes one of the major challenges in real-world self-driving scenarios. Existing BEV-based (i.e., Bird Eye View) detectors favor sparse convolutions (known as SPConv) to speed up training and inference, which puts a hard barrier for deployment, especially for on-device applications. In this paper, to tackle the challenge of efficient 3D object detection from an industry perspective, we devise a deployment-friendly pillar-based 3D detector, termed FastPillars. First, we introduce a novel lightweight Max-and-Attention Pillar Encoding (MAPE) module specially for enhancing small 3D objects. Second, we propose a simple yet effective principle for designing a backbone in pillar-based 3D detection. We construct FastPillars based on these designs, achieving high performance and low latency without SPConv. Extensive experiments on two large-scale datasets demonstrate the effectiveness and efficiency of FastPillars for on-device 3D detection regarding both performance and speed. Specifically, FastPillars delivers state-of-the-art accuracy on Waymo Open Dataset with 1.8X speed up and 3.8 mAPH/L2 improvement over CenterPoint (SPConv-based). # 3. Network Architecture Overview

We focus on the grid based models due to the runtime efficiency and proximity to 2D object detection. Typically, a grid based network is composed of (i) a grid encoder to convert raw point clouds into structured feature maps, (ii) a backbone for general feature extraction, (iii) a neck for multi-scale feature fusion, and (iv) a detection head for the task-specific output. Existing works often couple all these components together. In this section, we have them decoupled and review each part briefly.

# 3.1. Grid Encoder

A grid encoder is used to discretize point clouds into structured grids, and then convert and aggregate the points within each grid into the preliminary feature representation. In this work, we target at the following three grid encoders.

- **Pillar:** A pillar based grid encoder arranges points in vertical columns, and applies multilayer perceptrons (MLPs) followed by max pooling to extract pillar features, which are represented as a pseudo image [14].
- **Voxel:** Similar to pillar, the voxel based grid encoder organizes points in voxels and obtains corresponding features [47]. Compared with pillar, the voxel encoder preserves details along the height dimension.
- **Multi-View Fusion (MVF):** A MVF based grid encoder combines the pillar/voxel and range view based representations. Here we follow [43] to incorporate a pillar encoder with a cylindrical view based encoder that groups points in the cylindrical coordinates.

A backbone performs further feature abstraction based on the preliminary features extracted by the grid encoder. For fair comparisons, we utilize ResNet-18 as the backbone, since it is commonly used in the previous works [32,45,49]. **1. Introduction**

Multi-task learning aims to improve learning efficiency and prediction accuracy by learning multiple objectives from a shared representation [7]. Multi-task learning is prevalent in many applications of machine learning – from computer vision [27] to natural language processing [11] to speech recognition [23].

We explore multi-task learning within the setting of visual scene understanding in computer vision. Scene understanding algorithms must understand both the geometry and semantics of the scene at the same time. This forms an interesting multi-task learning problem because scene understanding involves joint learning of various regression and classification tasks with different units and scales. Multi-task learning of visual scene understanding is of crucial importance in systems where long computation run-time is prohibitive, such as the ones used in robotics. Combining all tasks into a single model reduces computation and allows these systems to run in real-time.

3. Multi Task Learning with Homoscedastic Uncertainty

Multi-task learning concerns the problem of optimising a model with respect to multiple objectives. It is prevalent in many deep learning problems. The naive approach to combining multi objective losses would be to simply perform a weighted linear sum of the losses for each individual task:

L_total = Σ_i w_i L_i. (1)

This is the dominant approach used by prior work [39, 38, 30, 41], for example for dense prediction tasks [27], for scene understanding tasks [15] and for rotation (in quaternions) and translation (in meters) for camera pose [25]. However, there are a number of issues with this method. Namely, model performance is extremely sensitive to weight selection, w_i, as illustrated in Figure 2. These weight hyper-parameters are expensive to tune, often taking many days for each trial. Therefore, it is desirable to find a more convenient approach which is able to learn the optimal weights.

## Problem Context and Motivation

The field of 3D object detection has evolved through several architectural approaches. Point-based methods directly process raw point clouds but suffer from complex 3D operations unsuitable for efficient hardware implementation. Grid-based methods convert irregular point clouds into structured representations, with early voxel-based approaches using computationally expensive dense 3D convolutions.

SPConv-based methods revolutionized the field by operating only on non-empty voxels, significantly reducing computation. However, SPConv creates deployment challenges:

  * Incompatibility with TensorRT optimization
  * Difficulty in developing custom CUDA plugins
  * Poor quantization support
  * Irregular memory access patterns

Pillar-based methods like PointPillars offered deployment-friendly alternatives by using 2D convolutions, but their performance typically lagged behind SPConv-based approaches due to information loss in pillarization and less efficient backbones.

FastPillars aims to bridge this performance-deployment gap by achieving SPConv-level accuracy with pillar-based deployment friendliness.

## Architecture and Methodology

FastPillars follows a conventional four-stage pipeline: Pillar Feature Encoding (PFE), Backbone, Neck, and Head. Its innovations lie primarily in the first two components.

### Max-and-Attention Pillar Encoding (MAPE)

The MAPE module addresses information loss in traditional pillar aggregation methods. It consists of three components:

  1. Point Encoding: Raw point features (coordinates, intensity, timestamp) are augmented with relative positional information and processed through an MLP to create high-dimensional representations.
The architectural principles established, particularly regarding computation allocation for geometric data processing, may influence future 3D detection network designs beyond the immediate application domain.

Pointpillars: Fast encoders for object detection from point clouds

This is the pioneering work for pillar-based 3D object detection. The FastPillars model is a direct successor to this approach, aiming to significantly improve upon PointPillars' performance while retaining its core deployment-friendly and SPConv-free architecture.

Lang, A. H.; Vora, S.; Caesar, H.; Zhou, L.; Yang, J.; and Beijbom, O. 2019. Pointpillars: Fast encoders for object detection from point clouds. In CVPR, 12697–12705.

Center-based 3d object detection and tracking

This paper introduces CenterPoint, which is the primary state-of-the-art benchmark used for comparison throughout the FastPillars paper. FastPillars demonstrates its effectiveness by showing significant speed and accuracy improvements over CenterPoint, and it also adopts its center-based detection head.

Yin, T.; Zhou, X.; and Krahenbuhl, P. 2021a. Center-based 3d object detection and tracking. 11784–11793.

PillarNet: Real-Time and High-Performance Pillar-based 3D Object Detection

PillarNet is a contemporary high-performance pillar-based detector that relies on sparse convolutions (SPConv). FastPillars explicitly positions itself as a superior alternative by achieving comparable or better performance without SPConv, thus avoiding the deployment difficulties associated with methods like PillarNet.

Shi, G.; Li, R.; and Ma, C. 2022. PillarNet: Real-Time and High-Performance Pillar-based 3D Object Detection.

Second: Sparsely embedded convolutional detection

This paper is foundational for introducing sparse convolutions (SPConv) to accelerate 3D detection networks. A core premise of FastPillars is to create a deployment-friendly model by eliminating the need for SPConv, making this reference essential for understanding the technical challenge that FastPillars was designed to overcome.

Yan, Y.; Mao, Y.; and Li, B. 2018. Second: Sparsely embedded convolutional detection. Sensors, 18(10): 3337.
