\textit{2. Performance on Vulnerable Road Users (Pedestrian).}
In autonomous driving perception, detecting small, non-rigid objects such as pedestrians represents the most challenging operational regime due to extreme point sparsity and severe aspect-ratio disparity. As evidenced in Table~\ref{tab:comparison} and the Precision--Recall curves in Figure~\ref{fig:pr_curves}, MobilePIXORNeXt achieves \textbf{60.75\% Moderate AP} on Pedestrians, outperforming PointPillars ($56.01\%$, a $+4.74\%$ gain) and SECOND ($56.56\%$, a $+4.19\%$ gain), while more than doubling the baseline MobilePIXOR ($28.16\%$, a $+32.59\%$ gain). We attribute this performance advantage primarily to two complementary factors: (i) Strata-BEV14's continuous subcell displacement offsets $(\Delta\bar{x}, \Delta\bar{y})$, which mitigate the $0.1\,\text{m}$ grid quantization error that inherently impairs small object localization; and (ii) the decoupled GroupedHeader architecture, which isolates pedestrian regression from large vehicle footprints to alleviate gradient interference across morphologically disparate categories.

While two-stage 3D anchor-based detectors (PointRCNN, Part-A$^2$, PV-RCNN) achieve higher absolute accuracy on rigid vehicles, they require between $4.0\,\text{M}$ and $63.8\,\text{M}$ parameters and operate at higher latencies ($133\text{--}195\,\text{ms}$), exceeding the real-time constraints of embedded edge processors.

\subsection{Inference Latency and Real-Time Complexity}
\label{sec:latency_analysis}
\input{tables/efficiency}

\paragraph{Pipeline Latency vs. Model Forward Throughput.}
In real-time autonomous systems, evaluating neural network forward execution time in isolation yields a misleading depiction of deployability. A complete perception system must account for point cloud loading, input feature tensorization, Host-to-Device (H2D) memory transfer, forward execution, coordinate decoding, and Non-Maximum Suppression (NMS). Table~\ref{tab:efficiency} provides a rigorous latency breakdown across all $3{,}769$ validation scans measured on an NVIDIA Tesla T4 GPU under batch size 1.



\textit{1. End-to-End Pipeline Latency Comparison.}
As detailed in Table~\ref{tab:efficiency}, MobilePIXORNeXt achieves an End-to-End (E2E) pipeline latency of \textbf{60.96\,ms} (\textbf{16.41\,FPS}), achieving the lowest full-system latency among all evaluated real-time detectors. It operates faster than PointPillars ($63.84\,\text{ms}$, $15.66\,\text{FPS}$), MobilePIXOR ($85.92\,\text{ms}$, $11.64\,\text{FPS}$), and SECOND ($93.70\,\text{ms}$, $10.67\,\text{FPS}$), and runs over $2.3\times$ faster than the original PIXOR ($144.00\,\text{ms}$, $6.94\,\text{FPS}$). Percentile analysis indicates consistent latency bounds in the evaluated environment: MobilePIXORNeXt exhibits a median P50 latency of \textbf{58.28\,ms}, P95 of $80.85\,\text{ms}$, and P99 of $95.91\,\text{ms}$, demonstrating low latency dispersion under desktop GPU benchmarking.

\textit{2. Component Latency Profiling and Host-to-Device Efficiency.}
Stage-by-stage profiling reveals the underlying mechanics of our throughput advantage:
\begin{itemize}
    \item \textbf{Preprocessing and Rasterization ($20.94\,\text{ms}$)}: By utilizing our deterministic parallel Numba kernel with precomputed logarithmic lookup tables, Strata-BEV14 rasterizes raw scans in $20.94\,\text{ms}$ on CPU, faster than PointPillars ($27.75\,\text{ms}$) and SECOND ($27.20\,\text{ms}$) which require sorting and pillar grouping.
    \item \textbf{Host-to-Device Memory Transfer ($6.91\,\text{ms}$)}: Unlike 35-channel binary occupancy tensors that require transferring $78.8\,\text{MB}$ per scan, Strata-BEV14's compact 14-channel layout requires transferring only $31.5\,\text{MB}$ (a $60.0\%$ payload reduction), which, in conjunction with pinned-memory buffer optimization, reduces H2D latency to $6.91\,\text{ms}$ compared with $40.63\,\text{ms}$ for the MobilePIXOR baseline.
    \item \textbf{Model Forward Propagation ($17.88\,\text{ms}$, $55.94\,\text{FPS}$)}: Network inference executes in $17.88\,\text{ms}$ on Tesla T4. In optimized standalone inference, the network reaches \textbf{115.32\,FPS} ($8.67\,\text{ms}$).
    \item \textbf{Decoding and Rotated NMS ($14.94\,\text{ms}$)}: Candidate peak selection and class-wise rotated NMS execute in $14.94\,\text{ms}$, maintaining GPU residency until final bounding box export.
\end{itemize}

\subsection{Ablation Studies}
\label{sec:ablations}

\paragraph{Systematic Architectural Progression.}
To quantify the individual and cumulative contributions of the proposed components, Table~\ref{tab:components} details the step-by-step ablation progression from the baseline to the final configuration.

\input{tables/components}

\par\vspace{0.5\baselineskip}

\textit{1. Backbone Architecture (A0 $\to$ A1).}
Replacing MobilePIXOR's residual blocks with our ConvNeXt-style backbone ($7 \times 7$ depthwise convolutions, inverted bottleneck expansion $e=2.5$, SiLU activations, and LayerScale) elevates Moderate mAP from $41.40\%$ to $47.60\%$ (\textbf{+6.20\% mAP}), while nearly doubling standalone forward throughput from $90.57$ to \textbf{169.97\,FPS}. Large depthwise kernels significantly broaden spatial receptive fields on BEV grids without inflating computational complexity.


\par\vspace{0.5\baselineskip}
\textit{2. BEV Input Representation (A1 $\to$ A2 $\to$ A3).}
Replacing 35-channel binary slicing (A1, $47.60\%$) with 8-channel RichBEV (A2, $47.37\%$) maintains comparable accuracy with fewer channels. Upgrading to our 14-channel Strata-BEV14 (A3) increases Moderate mAP to $50.14\%$ (\textbf{+2.54\% mAP}). Encoding continuous elevation moments ($z_{\max}, z_{\mathrm{mean}}, z_{\mathrm{span}}, z_{\mathrm{std}}$) and subcell centroid displacements eliminates horizontal discretization errors.

\par\vspace{0.5\baselineskip}
\textit{3. Decoupled Grouped Prediction Towers (A3 $\to$ A4 $\to$ A5).}
Partitioning prediction heads into separate Car and Ped/Cyc groups (A4) yields an immediate gain to $51.30\%$ mAP over A3. Expanding grouped head capacity from 16 to 32 channels (A5) produces a further gain to $60.22\%$ Moderate mAP (\textbf{+8.92\% mAP}) and $61.11\%$ $\text{mAP}_9$ compared with configuration A4. Decoupling isolates class-specific representations, mitigating gradient interference between morphologically distinct categories such as passenger vehicles and pedestrians.


\par\vspace{0.5\baselineskip}
\textit{4. Physics-Consistent Ground-Truth Augmentation (A5 $\to$ A6).}
Transitioning from standard ground-truth sampling to our physics-consistent augmentation (\texttt{PC-GTA}) yields a gain of \textbf{+6.03\% mAP} over configuration A5, advancing Moderate mAP from $60.22\%$ to $66.25\%$ and $\text{mAP}_9$ from $61.11\%$ to $68.45\%$ (\textbf{+7.34\% mAP}). Enforcing terrain surface alignment, rejecting obstacle collisions, casting raycast shadows, and attenuating point density according to range reduces unphysical artifacts that can degrade network training.

\par\vspace{0.5\baselineskip}
\textit{5. Multiscale Neck and Scale Gating (A6 $\to$ A7 $\to$ A8).}
Widening the neck fusion layer from 24 to 32 channels (A7) increases Moderate mAP to $68.12\%$ (\textbf{+1.87\% mAP}). Incorporating the Top-Down Scale-Gated FPN (A8) replaces transposed convolutions with bilinear upsampling and learnable depthwise scale gating, eliminating deconvolution checkerboard artifacts on continuous regression maps.

\par\vspace{0.5\baselineskip}
\textit{6. Geometric Supervision and Localization Quality (A8 $\to$ A9).}
Supervising the network with Oriented Geometric Alignment (OGA) and IoU-Aware Quality Alignment (IQA) drives Moderate mAP from $67.38\%$ to $70.58\%$ (\textbf{+3.20\% mAP}). Coupling Multi-Axis Projection GIoU with scale-normalized $\pi$-symmetric corner distances aligns loss gradients directly with rotated bounding box overlap, while IQA confidence calibration prevents high-scoring but misaligned false positives from surviving NMS.


\par\vspace{0.5\baselineskip}
\textit{7. Block-SimAM Energy Attention (A9 $\to$ A10).}
Embedding parameter-free Block-SimAM inside every residual block across stages C2, C3, and C4 culminates in our final configuration, achieving \textbf{71.46\% Moderate mAP} and \textbf{73.42\% mAP$_9$} (\textbf{+0.88\% mAP}).
Compared with the no-attention configuration, block-level SimAM raises Moderate mAP by 0.88 percentage points and $\text{mAP}_9$ by 0.76 points, with a $0.48\,\text{ms}$ increase in standalone forward latency. The final configuration also combines OGA and IQA; the following factorial study isolates each component's contribution.
Block-SimAM gains 1.66--2.10 mAP points over stage-level variants at 115.32 vs. 144.05 standalone FPS.


\paragraph{Geometric Supervision and Quality Head Factorial Study.}
Table~\ref{tab:loss} presents a $2 \times 2$ factorial evaluation isolating the effects of OGA geometric supervision and the explicit IQA prediction branch.

\input{tables/loss}

As shown in Table~\ref{tab:loss}, introducing OGA alone into baseline training increases Moderate mAP from $67.38\%$ to $68.97\%$ (\textbf{+1.59\% mAP}), with consistent gains across Car ($+0.17\%$), Pedestrian ($+2.45\%$), and Cyclist ($+2.14\%$). Enabling IQA alone on the baseline elevates mAP to $70.31\%$ (\textbf{+2.93\% mAP}). Combining both OGA and IQA achieves the highest accuracy of \textbf{70.58\% Moderate mAP}, producing peak performance on Car ($84.87\%$) and Pedestrian ($59.63\%$). These findings demonstrate that OGA and IQA provide complementary benefits: OGA refines continuous corner and boundary alignment during backpropagation, whereas IQA calibrates classification scores with true geometric overlap during inference ($S_{\mathrm{det}} = \sqrt{P_{\mathrm{cls}}\hat{q}}$), preventing misaligned boxes from suppressing high-quality candidates during rotated NMS.

Crucially, the complexity metrics in Table~\ref{tab:loss} demonstrate an architectural trade-off between explicit multi-branch quality prediction and head-free quality coupling. Models incorporating the dedicated IQA prediction branch require $0.721\,\text{M}$ parameters and execute at $8.19\,\text{ms}$ forward latency ($122.16\,\text{FPS}$). In contrast, the head-free Q-OGA formulation (Eq.~(\ref{eq:cqfl_target})--(\ref{eq:cqfl_loss})) omits the auxiliary IQA heads, preserving the minimal $0.702\,\text{M}$ parameter budget (saving $18.59\,\text{K}$ parameters) and achieving a faster forward speed of $6.94\,\text{ms}$ ($144.16\,\text{FPS}$). Without any extra prediction branches or post-processing score multiplications, Q-OGA reaches $69.20\%$ Moderate mAP, outperforming standalone OGA by $+0.23\%$ mAP and surpassing the baseline Smooth-L1 by $+1.82\%$ mAP. This demonstrates that Q-OGA is an optimal solution for resource-constrained edge platforms where parameter memory and latency budgets are strictly capped, whereas the explicit IQA configuration offers peak accuracy ($70.58\%$) when resources permit a dedicated quality branch.

\subsection{Discussion and Practical Limitations}
\label{sec:discussion_limitations}

\paragraph{Discussion and Insights.}
The empirical results indicate that high-accuracy 3D LiDAR object detection does not strictly necessitate parameter-heavy point-cloud encoders or computationally demanding 3D sparse convolutions. By enriching the deterministic 2D BEV representation with multi-band vertical densities, elevation dispersion moments, and continuous subcell centroid displacements, a streamlined ConvNeXt-style 2D convolutional network extracts expressive geometric features with fewer than $0.76\,\text{M}$ parameters. Furthermore, enforcing physical realism in data augmentation (\texttt{PC-GTA}) and resolving multi-task gradient competition through decoupled grouped heads provide larger empirical performance gains than model depth scaling alone.

\paragraph{Limitations and Future Scope.}
The current MobilePIXORNeXt architecture operates primarily on oriented 2D Bird's-Eye View footprints ($x, y, l, w, \psi$), which represents the optimal perception trade-off for autonomous vehicle motion planning and collision avoidance under strict edge-computing power envelopes. Although 3D bounding box estimation ($z, h$) is supported via our optional vertical prediction head, full 3D height estimation on heavily sloped terrains remains an active area of investigation. Future research will explore range-conditioned frequency modulations (RC-SGFPN) and hardware-specific TensorRT INT8 quantization for ultra-low-power micro-mobility microcontrollers.
