MobilePIXORNeXt is a compact, proposal-free, multi-class three-dimensional (3D) object detector designed for real-time Light Detection and Ranging (LiDAR) perception on resource-constrained embedded platforms. Operating strictly on an efficient Bird's-Eye View (BEV) representation, the framework eliminates computationally expensive learned point-cloud feature encoders and three-dimensional sparse convolutions. Figure~\ref{fig:r37_overview} provides a comprehensive overview of the overall detection pipeline, detailing the end-to-end data flow from the raw point cloud to the final decoded oriented bounding boxes.

\subsection{Problem Formulation and Input/Output Contracts}
\label{sec:problem_formulation}

\paragraph{LiDAR Coordinate Frame and Spatial Region of Interest.}
An unordered LiDAR point cloud is acquired via a rotating scanner and defined as a set $\mathcal{P} = \{\mathbf{p}_i\}_{i=1}^{N_{\mathrm{pts}}}$, where each point $\mathbf{p}_i = (x_i, y_i, z_i, \iota_i) \in \mathbb{R}^4$ encapsulates longitudinal distance $x_i$ (forward positive), lateral distance $y_i$ (leftward positive), vertical elevation $z_i$ (upward positive), and calibrated reflectance intensity $\iota_i \in [0, 1]$. Perception is constrained to a fixed Cartesian Region of Interest (ROI):
\begin{equation}
    \begin{aligned}
        x_i &\in [x_{\min}, x_{\max}], \\
        y_i &\in [y_{\min}, y_{\max}], \\  z_i &\in [z_{\min}, z_{\max}].
    \end{aligned}
    \label{eq:spatial_roi}
\end{equation}
configured with longitudinal bounds $[0.0, 70.4]$\,m, lateral bounds $[-40.0, 40.0]$\,m, and vertical bounds $[-2.5, 1.0]$\,m. An open-boundary inward margin of $\epsilon = 0.001$\,m is enforced to eliminate boundary artifacts. Discretizing the horizontal plane with a uniform spatial resolution of $\Delta_x = \Delta_y = 0.1$\,m produces a discrete grid of size $H_{\mathrm{in}} \times W_{\mathrm{in}} = 800 \times 704$ cells. A point $\mathbf{p}_i$ is deterministically indexed into grid coordinate $(u_i, v_i)$ via:
\begin{equation}
    u_i = \left\lfloor \frac{x_i - x_{\min}}{\Delta_x} \right\rfloor, \qquad v_i = \left\lfloor \frac{y_i - y_{\min}}{\Delta_y} \right\rfloor.
    \label{eq:grid_assignment}
\end{equation}

\paragraph{Detection Target Contract.}
The detector predicts oriented bounding boxes projected onto the horizontal BEV plane across three semantic categories: Car ($c=0$), Pedestrian ($c=1$), and Cyclist ($c=2$). At an output spatial downsampling factor of $s_{\mathrm{out}} = 4$, the output feature map resolution is $H_{\mathrm{out}} \times W_{\mathrm{out}} = 200 \times 176$. For each detected object instance $k$, the target state is parameterized by the 7-tuple:
\begin{equation}
    \mathbf{b}_k = (c_k, x_k^*, y_k^*, l_k^*, w_k^*, \psi_k^*, s_k),
    \label{eq:target_tuple}
\end{equation}
where $(x_k^*, y_k^*) \in \mathbb{R}^2$ denotes the metric continuous center coordinates, $(l_k^*, w_k^*) \in \mathbb{R}^2$ represents length and width footprints, $\psi_k^* \in [-\pi/2, \pi/2]$ is the orientation heading angle under a $\pi$-symmetric doubled-angle representation, and $s_k \in [0, 1]$ is the calibrated detection confidence score. Operating on this contract requires a structured, dense BEV representation that captures fine 3D geometric distributions without the latency of learned point encoders, which we formulate next.

\subsection{Deterministic Strata-BEV14 Feature Representation}
\label{sec:strata_bev14}

\paragraph{Motivation.}
Voxel- and pillar-based detectors~\cite{lang2019pointpillars,li2023pillarnext} rely on PointNet-style column encoders, adding computation and padding overhead. By contrast, 35-channel binary slicing~\cite{yang2018pixor} omits continuous height and reflectance cues, while three-channel height bands~\cite{khoshkdahan2026triband} lack higher-order geometry. We therefore propose \textbf{Strata-BEV14}, a deterministic, parameter-free rasterizer that balances detail and efficiency.


\paragraph{Mathematical Formulation.}
For each occupied cell $(u, v)$ containing $N$ points $\mathcal{P}_{u, v} = \{\mathbf{p}_i\}_{i=1}^N$, vertical elevations are normalized linearly to unit interval $\zeta_i = (z_i - z_{\min}) / (z_{\max} - z_{\min}) \in [0, 1]$, and reflectance values $\iota_i$ are clamped to $[0, 1]$. Strata-BEV14 computes fourteen analytical features across four functional groups, summarized in Table~\ref{tab:strata_bev14}:

1. \textit{Height-Stratified Density Channels ($F_0$--$F_3$)}: Normalized height $\zeta_i$ is partitioned into four uniform vertical intervals $b \in \{0, 1, 2, 3\}$. For bin point count $N_b$, a logarithmic compression is applied to mitigate LiDAR ray density fall-off over range:
\begin{equation}
    F_b = d_{\log}(N_b) = \min\left(1, \frac{\ln(1 + N_b)}{\ln(1 + N_{\mathrm{norm}})}\right),
    \label{eq:density_encoding}
\end{equation}
where $N_{\mathrm{norm}} = 32$ is a normalization constant chosen to saturate at dense returns.

2. \textit{Vertical Spatial Moments ($F_4$--$F_7$)}: To encode obstacle geometry without explicit voxelization, we extract peak elevation $F_4 = \max_i \zeta_i$, mean elevation $F_5 = \frac{1}{N}\sum_i \zeta_i$, vertical span $F_6 = \max_i \zeta_i - \min_i \zeta_i$, and the sample standard deviation:
\begin{equation}
    F_7 = \begin{cases}
        \sqrt{\max\left(0, \frac{1}{N} \sum_{i=1}^N \zeta_i^2 - F_5^2\right)}, & \text{if } N > 1, \\
        0, & \text{otherwise}.
    \end{cases}
    \label{eq:z_std_encoding}
\end{equation}

3. \textit{Reflectance Statistics ($F_8$--$F_9$)}: Calibrated surface returns capture material discrimination (e.g., distinguishing retro-reflective license plates, pedestrian clothing, or road signs):
\begin{equation}
    F_8 = \max_{i=1,\dots,N} \iota_i, \qquad F_9 = \frac{1}{N} \sum_{i=1}^N \iota_i.
    \label{eq:intensity_encoding}
\end{equation}

4. \textit{Occupancy and Continuous Subcell Offsets ($F_{10}$--$F_{13}$)}: Channel $F_{10} = d_{\log}(N)$ records total point density, while $F_{11} = 1.0$ signifies non-empty occupancy. Crucially, to prevent quantization error from coarse $0.1$\,m cell discretization, channels $F_{12}$ and $F_{13}$ preserve continuous subcell horizontal centroid displacements:
\begin{align}
    x_u^{\mathrm{cell}} &= x_{\min} + (u + 0.5)\Delta_x, \nonumber\\
    y_v^{\mathrm{cell}} &= y_{\min} + (v + 0.5)\Delta_y, \nonumber\\
    F_{12} &= \operatorname{clip}\left(\frac{\sum_{i=1}^N (x_i - x_u^{\mathrm{cell}})}{N\Delta_x}, -0.5, 0.5\right), \nonumber\\
    F_{13} &= \operatorname{clip}\left(\frac{\sum_{i=1}^N (y_i - y_v^{\mathrm{cell}})}{N\Delta_y}, -0.5, 0.5\right).
    \label{eq:offset_encoding}
\end{align}
Empty cells are assigned zeros across all 14 channels, producing the structured input tensor $\mathbf{X} \in \mathbb{R}^{B \times 14 \times 800 \times 704}$.

\paragraph{Technical Advantage.}
Unlike PointNet-based pillars that require sorting, scatter operations, and multi-layer perceptron projections, Strata-BEV14 executes via a deterministic parallel CUDA kernel in under $21$\,ms. It enriches the BEV plane with continuous vertical distribution, material reflectance, and subcell resolution offsets prior to learned convolution.

\subsection{Physics-Consistent Ground-Truth Augmentation}
\label{sec:hybrid_augmentation}

\paragraph{Motivation.}
Cut-and-paste ground-truth (GT) augmentation balances rare LiDAR categories, but naive insertion ignores scene physics, producing floating or submerged objects, background collisions, missing raycast shadows, and unrealistic range-dependent point densities. Our \textbf{Physics-Consistent Ground-Truth Augmentation} (\texttt{PC-GTA}) addresses these artifacts and improves Moderate mAP by $+6.03\%$ over naive sampling in our ablations.

\paragraph{Design Heuristics.}
We apply five consistency checks when placing a box $\mathbf{b}_{\mathrm{insert}} = (x, y, z, l, w, h, \psi)$ at range $d = \sqrt{x^2 + y^2}$:
\begin{enumerate}
\item \textit{Adaptive Ground Plane Fitting}: To prevent floating or sunken objects, local road elevation is estimated within a range-dependent search radius:
\begin{align}
    R(d) &= \operatorname{clip}(2.5 + 0.03\max(0, d - 15), 2.5, 4.0)\,\mathrm{m},\nonumber\\[0.8em]
    \hat{z}_{\mathrm{ground}} &= \operatorname{percentile}(\{z_j \mid \mathbf{p}_j \in \mathcal{N}(x, y)\}, 5),
    \label{eq:ground_fitting}
\end{align}
where $\mathcal{N}(x, y) = \{\mathbf{p}_j \mid (x_j - x)^2 + (y_j - y)^2 \le R(d)^2\}$ denotes the local neighborhood used for ground estimation.
The inserted object elevation is anchored strictly flush with the terrain: $z_{\mathrm{insert}} = \hat{z}_{\mathrm{ground}} + 0.5h$.

\item \textit{Static Obstacle Clearance}: To prevent clipping into physical structures, a candidate box is rejected if existing background points within its bounding footprint exceed a strict clearance threshold: $N_{\mathrm{static}} \le N_{\mathrm{thresh}}$.

\item \textit{Line-of-Sight (LOS) Occlusion Check}: The optical ray from sensor origin to box center $(x, y)$ is cast. If existing dense clusters obstruct the trajectory, the insertion candidate is discarded.

\item \textit{Raycast LiDAR Shadow Masking}: In real LiDAR scans, solid foreground objects cast occlusive ray shadows that block returns from background objects behind them. For each inserted box, we compute geometric ray intersections $\mathbf{r}(t) = t \cdot \mathbf{p}$ for all background points $\mathbf{p}$. Points residing behind the exit face ($t_{\mathrm{leave}} \le 1.0$) with radial distance $(1 - t_{\mathrm{leave}})\|\mathbf{p}\| > 0.05$\,m are masked out:
\begin{equation}
    \begin{aligned}
        \mathcal{P}_{\mathrm{augmented}}
        &= \mathcal{P}_{\mathrm{target}} \setminus
        \{\mathbf{p} \in \mathcal{P}_{\mathrm{target}} \mid \\
        &\qquad \operatorname{Mask}_{\mathrm{shadow}}(\mathbf{p}) = \mathrm{True}\}
        \cup \mathcal{P}_{\mathrm{object}}.
    \end{aligned}
    \label{eq:shadow_mask}
\end{equation}

\item \textit{Range-Adaptive Point and Intensity Attenuation}: If an object captured at source distance $r_{\mathrm{src}}$ is placed at target distance $r_{\mathrm{tgt}} > r_{\mathrm{src}}$, its point cloud is randomly subsampled according to the inverse-square divergence law:
\begin{equation}
    P_{\mathrm{keep}} = \min\left(1, \left(\frac{r_{\mathrm{src}}}{r_{\mathrm{tgt}}}\right)^2\right),
    \label{eq:inverse_square}
\end{equation}
and reflectance intensity is attenuated according to:
\[
    \begin{aligned}
        \eta_{\mathrm{int}}
        &= \left(\frac{r_{\mathrm{src}}}{r_{\mathrm{tgt}}}\right)^{\max(0, 2 - \gamma)},
        \qquad \gamma = 1.7, \\
        I_{\mathrm{tgt}}
        &= \operatorname{clip}(I_{\mathrm{src}}\eta_{\mathrm{int}}, 0, 1).
    \end{aligned}
\]
\end{enumerate}
During training, the resulting physically consistent point cloud $\mathcal{P}_{\mathrm{augmented}}$ is rasterized into the 14-channel input tensor $\mathbf{X}$ and fed into the convolutional backbone hierarchy.

\label{sec:backbone_architecture}

\paragraph{Motivation.}
Target objects on the horizontal BEV plane exhibit significant geometric scale disparities: spanning from compact pedestrians ($l \approx 0.6$\,m) and cyclists ($l \approx 1.8$\,m) to passenger vehicles ($l \approx 4.5$--$5.0$\,m). Conventional backbones with small $3 \times 3$ convolutions require excessive network depth to cover the requisite spatial context, ballooning latency and parameter count. In contrast, at our input grid resolution of $\Delta_x = \Delta_y = 0.1$\,m, a single $7 \times 7$ depthwise receptive field directly spans $0.7 \times 0.7$\,m of physical terrain at stride 1, and rapidly expands to over $5.6 \times 5.6$\,m by Stage 3 (stride 8)---sufficient to envelop an entire passenger vehicle in a single layer without dilation artifacts. To achieve this wide context under strict parameter parsimony, we design the \textbf{MobilePixorNeXt Backbone} hierarchy featuring large $7 \times 7$ depthwise convolutions, inverted bottleneck expansions, and LayerScale residual stabilization organized into repeated \texttt{MobilePixorNeXt-S} blocks.

\paragraph{Backbone Topology and Multi-Stage Hierarchy.}
As depicted in Figure~\ref{fig:backbone}, the network topology comprises:
\begin{enumerate}
    \item \textit{Convolutional Stem}: Input $\mathbf{X} \in \mathbb{R}^{B \times 14 \times 800 \times 704}$ is ingested by two consecutive $3 \times 3$ convolutions (stride 2 followed by stride 1) with 32 output channels, Batch Normalization (BN), and Sigmoid Linear Unit (SiLU) activations, yielding stride-2 representation $\mathbf{F}^{(2)} \in \mathbb{R}^{B \times 32 \times 400 \times 352}$.
    \item \textit{Progressive Multi-Stage Hierarchy}: Three progressive stages are separated by strided transition downsample blocks (\texttt{DownsampleBlock}: Conv $3 \times 3$ stride 2 + BN + SiLU):
    \begin{itemize}
        \item Stage 2 (Stride 4): 2 \texttt{MobilePixorNeXt-S} blocks, $C_2 = 48 \rightarrow \mathbf{F}^{(4)} \in \mathbb{R}^{B \times 48 \times 200 \times 176}$.
        \item Stage 3 (Stride 8): 4 \texttt{MobilePixorNeXt-S} blocks, $C_3 = 96 \rightarrow \mathbf{F}^{(8)} \in \mathbb{R}^{B \times 96 \times 100 \times 88}$.
        \item Stage 4 (Stride 16): 2 \texttt{MobilePixorNeXt-S} blocks, $C_4 = 128 \rightarrow \mathbf{F}^{(16)} \in \mathbb{R}^{B \times 128 \times 50 \times 44}$.
    \end{itemize}
\end{enumerate}

\paragraph{Streamlined Single-Branch Depthwise Design.}
Unlike multi-branch reparameterization paradigms that mandate complex multi-path training topologies and post-hoc weight folding, MobilePIXORNeXt directly trains and deploys a clean single-branch large-kernel ($7 \times 7$) depthwise convolution. By pairing wide spatial receptive fields with inverted bottleneck expansion ($e=2.5$) and LayerScale stabilization, the backbone achieves rapid optimization convergence and fast throughput ($55.94$\,FPS on Tesla T4) without incurring auxiliary branch memory overhead during backpropagation. The complete backbone comprises only $604,864$ parameters.

\paragraph{Micro-Architecture and Inverted Bottleneck.}
Figure~\ref{fig:next_s_block} illustrates the \texttt{MobilePixorNeXt-S} residual block. Given input tensor $\mathbf{Z} \in \mathbb{R}^{B \times C \times H \times W}$, each block applies an inverted bottleneck with expansion ratio $e = 2.5$:
\begin{align}
    \mathbf{V} &= \operatorname{BN}(\operatorname{DWConv}_{7\times7}(\mathbf{Z})),\nonumber\\
    \mathbf{R} &= \operatorname{BN}\left(W_{\mathrm{red}} \operatorname{SiLU}(W_{\mathrm{exp}}\mathbf{V})\right),\nonumber\\
    \mathbf{Z}' &= \mathbf{Z} + \boldsymbol{\gamma}_{\mathrm{blk}} \odot \mathcal{S}(\mathbf{R}).
    \label{eq:next_block}
\end{align}
Here, $W_{\mathrm{exp}} \in \mathbb{R}^{2.5C \times C \times 1 \times 1}$ and $W_{\mathrm{red}} \in \mathbb{R}^{C \times 2.5C \times 1 \times 1}$ are pointwise $1 \times 1$ convolutions. The operator $\mathcal{S}(\cdot)$ represents our Block-SimAM attention module, while $\boldsymbol{\gamma}_{\mathrm{blk}} \in \mathbb{R}^C$ is a learned LayerScale parameter initialized to $10^{-5}$ to ensure numerical stability during deep backpropagation.

\paragraph{Parameter-Free Block-SimAM Spatial-Energy Attention.}
Standard attention modules such as Efficient Channel Attention (ECA-Net)~\cite{wang2020eca} or Squeeze-and-Excitation compute 1D channel attention weights by pooling across spatial dimensions, thereby treating all spatial locations identically. Conversely, non-local spatial attention requires quadratic computational complexity $\mathcal{O}((HW)^2)$, rendering it prohibitive for real-time dense BEV grids ($200 \times 176$). To address this trade-off, we integrate \textbf{Block-SimAM}~\cite{yang2021simam}---a 3D spatial-energy attention module operating without adding a single learned parameter.

\paragraph{Design and Placement.}
As illustrated in Figure~\ref{fig:next_s_block}, SimAM is embedded inside each \texttt{MobilePixorNeXt-\allowbreak S} block across all three stages (C2, C3, C4), for eight attention operators in total. It operates on the intermediate tensor $\mathbf{R} \in \mathbb{R}^{B \times C \times H \times W}$ after projection BN and before LayerScale shortcut addition.

For each channel slice with $M = H \times W$ spatial locations, spatial mean $\mu_c$ and sample variance $\nu_c$ are computed:
\begin{equation}
    \begin{aligned}
        \mu_c &= \frac{1}{M}\sum_{u, v} R_{c, u, v}, \\
        \nu_c &= \frac{1}{\max(M-1, 1)}\sum_{u, v} (R_{c, u, v} - \mu_c)^2.
    \end{aligned}
    \label{eq:spatial_moments}
\end{equation}
Derived from visual neuroscience principles of spatial energy minimization, the analytical minimal energy of a target neuron $t = R_{c, u, v}$ relative to its local background is given by:
\begin{equation}
    e_t = \frac{(t - \mu_c)^2}{4(\nu_c + \lambda_{\mathrm{sim}})} + \frac{1}{2},
    \label{eq:simam_energy}
\end{equation}
where $\lambda_{\mathrm{sim}} = 10^{-4}$ is a numerical regularizer. Neurons exhibiting greater variance from their spatial surround yield lower energy $e_t$, indicating higher visual saliency. The attended 3D modulation tensor $\mathbf{A} \in [0, 1]^{B \times C \times H \times W}$ and output $\mathcal{S}(\mathbf{R})$ are:
\begin{equation}
    A_{c, u, v} = \sigma(e_t) = \frac{1}{1 + e^{-e_t}}, \qquad \mathcal{S}(\mathbf{R}) = \mathbf{A} \odot \mathbf{R}.
    \label{eq:simam_modulation}
\end{equation}
Moments and gating scalars are computed in FP32 precision to prevent underflow, then multiplied elementwise with features.

\paragraph{Technical Advantage.}
Unlike stage-level adapters that add learned linear projections, Block-SimAM adds exactly \textbf{zero parameters} ($0$\,M). It simultaneously assigns true 3D spatial-and-channel attention weights, adaptively amplifying sparse LiDAR point clusters against flat terrain backgrounds. Empirical evaluation confirms that embedding SimAM inside each \texttt{MobilePixorNeXt-S} block achieves $+0.92\%$ mAP over the unaugmented baseline, outperforming stage-level adapters by up to $+2.14\%$ mAP.


\subsection{Top-Down Scale-Gated Feature Pyramid Network (SG-FPN Neck)}
\label{sec:neck_architecture}



\paragraph{Motivation.}
Standard Feature Pyramid Networks rely on transposed convolutions (deconvolutions) to upsample low-resolution feature maps, frequently introducing severe high-frequency checkerboard artifacts on continuous coordinate regression grids. Furthermore, while bidirectional multiscale networks (such as PANet or BiFPN) introduce cyclic bottom-up pathways that substantially inflate memory latency on edge accelerators, direct unweighted elementwise addition in conventional FPN causes semantic feature dilution. To resolve this, we design the \textbf{Top-Down Scale-Gated Feature Pyramid Network} (\texttt{SG-FPN Neck})---an efficient, unidirectional top-down fusion neck equipped with depthwise scale-gating.

\par


\paragraph{Mathematical Formulation.}
As shown in Figure~\ref{fig:scale_gated_fusion}, lateral features from Stages C4 ($128$\,ch), C3 ($96$\,ch), and C2 ($48$\,ch) are projected via $1 \times 1$ convolutions into matching lateral dimensions $\mathbf{L}_5 \in \mathbb{R}^{B \times 48 \times 50 \times 44}$, $\mathbf{L}_4 \in \mathbb{R}^{B \times 48 \times 100 \times 88}$, and $\mathbf{L}_3 \in \mathbb{R}^{B \times 32 \times 200 \times 176}$.

The feature aggregation proceeds strictly along a unidirectional top-down path. Spatial upsampling is performed using $2\times$ interpolation followed by depthwise $3 \times 3$ refinement convolution, BN, and SiLU to yield top-down features $\mathbf{U}_4$ and $\mathbf{U}_3$. At each fusion stride $r \in \{8, 4\}$, lateral and top-down representations are adaptively balanced via learnable depthwise scale gating:
\begin{align}
    \mathbf{G}_r &= 2\sigma\left(\operatorname{DWConv}_{3\times3, r}(\mathbf{L}_r + \mathbf{U}_r)\right),\nonumber\\
    \mathbf{P}^{(r)} &= \mathbf{U}_r + \mathbf{G}_r \odot \mathbf{L}_r.
    \label{eq:scale_gating}
\end{align}
Because depthwise gating weights and biases are initialized to zero, gating $\mathbf{G}_r$ initially evaluates to $1.0$, smoothly starting from standard residual addition. Finally, $\mathbf{P}^{(4)}$ is projected via a $3 \times 3$ convolution, BN, and SiLU to produce the shared detector representation $\mathbf{F}_{\mathrm{out}} \in \mathbb{R}^{B \times 32 \times 200 \times 176}$. The complete neck requires only $36,784$ parameters, delivering this calibrated multi-scale representation directly to the prediction towers.

\subsection{Shared Grouped Prediction Towers}
\label{sec:grouped_heads}

\par\vspace{-0.5\baselineskip}
\noindent
\begin{minipage}{\columnwidth}
    \centering
    \paperfigure{geometry_output_2x2.pdf}{75mm}{Geometric parameterization, orientation encoding, and quality-aware score calibration across prediction heads: (a) Continuous subcell coordinate offsets $(\Delta x, \Delta y)$ from anchor point $P$ to object center $C$; (b) Log-transformed bounding box dimension targets $(\log w, \log l)$; (c) Doubled-angle trigonometric yaw representation $(c_2, s_2) = (\cos 2\theta, \sin 2\theta)$ on the unit circle resolving $\pi$-heading ambiguity; and (d) IoU-quality-aware composite score ranking $s = (p_{\mathrm{cls}})^{1-\alpha} q^{\alpha}$ calibrated for post-processing peak selection and rotated NMS.}
    \captionof{figure}{Geometric parameterization, orientation encoding, and quality-aware score calibration in the decoupled prediction heads. \textbf{(a)} Continuous metric subcell offsets $(\Delta x, \Delta y)$ from anchor point $P$ to object center $C$. \textbf{(b)} Logarithmic dimension regression targets $(\log w, \log l)$. \textbf{(c)} Doubled-angle trigonometric yaw representation $(c_2, s_2) = (\cos 2\theta, \sin 2\theta)$ on the unit circle resolving $\pi$-heading ambiguity. \textbf{(d)} IoU-quality-aware composite score ranking $s = (p_{\mathrm{cls}})^{1-\alpha} q^{\alpha}$ calibrated for peak selection and class-wise rotated NMS.}
    \label{fig:geometry_output}
\end{minipage}
\par

\paragraph{Motivation.}
Autonomous driving involves drastic morphological discrepancies across object categories. Cars exhibit rigid rectangular footprints ($l \approx 4.5$\,m, $w \approx 1.8$\,m), whereas Pedestrians ($l \approx 0.8$\,m, $w \approx 0.6$\,m) and Cyclists ($l \approx 1.8$\,m, $w \approx 0.7$\,m) are compact and highly deformable. Forcing a single shared prediction head to jointly regress all classes induces severe gradient competition and scale interference. Conversely, dedicating entirely separate heads to each class inflates parameter size. We resolve this via \textbf{Shared Grouped Prediction Towers} (\texttt{GroupedHeader}).

\paragraph{Topology and Target Formulation.}
Classes are partitioned into two semantically compatible task groups: Group 1 for \texttt{car} ($K_1 = 1$), and Group 2 for \texttt{ped\_cyc} ($K_2 = 2$). For each group $g \in \{1, 2\}$, feature map $\mathbf{F}_{\mathrm{out}}$ passes through a group-shared initial $3 \times 3$ Conv-BN-SiLU block ($32 \rightarrow 32$ channels), before bifurcating into five task-specific prediction branches:
\begin{itemize}
    \item \texttt{cls}: Classification heatmap $[B, K_g, 200, 176]$ yielding foreground category probability $p_{\mathrm{cls}}$ at grid point $P$ (Fig.~\ref{fig:geometry_output}d).
    \item \texttt{offset}: Metric subcell coordinate offsets $[B,\allowbreak 2,\allowbreak 200,\allowbreak 176]$ predicting $(\hat{o}_x, \hat{o}_y)$, corresponding to continuous displacements $(\Delta x, \Delta y)$ from anchor point $P$ to object center $C$ (Fig.~\ref{fig:geometry_output}a).
    \item \texttt{size}: Bounding box log-dimensions $[B, 2, 200, 176]$ predicting $(\hat{d}_1, \hat{d}_2) = (\log \hat{w}, \log \hat{l})$ (denoted as regression targets $(t_w, t_l)$ in Fig.~\ref{fig:geometry_output}b, decoded via $\exp$).
    \item \texttt{yaw}: Orientation doubled-angle vector $[B, 2, 200, 176]$ predicting $(\hat{a}_1, \hat{a}_2) = (\cos 2\hat{\psi}, \sin 2\hat{\psi})$ (denoted as $(c_2, s_2)$ with heading angle $\theta \equiv \hat{\psi}$ on the unit circle in Fig.~\ref{fig:geometry_output}c to resolve $\pi$-heading ambiguity).
    \item \texttt{iou}: Localization quality score $[B, 1, 200, 176]$ predicting continuous overlap $\hat{q} \in [0, 1]$ ($q(P)$ in Fig.~\ref{fig:geometry_output}d), fused with classification into composite ranking confidence $s_{\mathrm{det}} = (p_{\mathrm{cls}})^{1-\alpha} \hat{q}^\alpha = \sqrt{p_{\mathrm{cls}} \hat{q}}$ ($\alpha=0.5$).
\end{itemize}

For output cell $(u, v)$, the ground-truth geometric targets are formulated as:
\begin{align}
    \mathbf{o}^* &= \begin{pmatrix} x^* - (u s_{\mathrm{out}}\Delta_x + x_{\min}) \\ y^* - (v s_{\mathrm{out}}\Delta_y + y_{\min}) \end{pmatrix},\nonumber\\
    \mathbf{d}^* &= (\log w^*, \log l^*), \qquad \mathbf{a}^* = (\cos 2\psi^*, \sin 2\psi^*).
    \label{eq:gt_targets}
\end{align}
The doubled-angle formulation $\mathbf{a}^*$ strictly enforces $\pi$-rotational symmetry, resolving the $180^\circ$ heading ambiguity inherent to symmetric BEV bounding boxes. Classification targets use 2D Gaussian heatmaps centered at continuous object projections with a minimum radius of 4 cells, and regression targets are assigned within a radius of half the Gaussian peak, denoted by valid indicator mask $\mathbf{M}_{\mathrm{reg}}$.

\subsection{Multi-Task Geometric Alignment and Quality Supervision (OGA and IQA)}
\label{sec:losses_and_oga}

\paragraph{Motivation.}
We propose \textbf{Oriented Geometric Alignment (OGA)} combined with \textbf{IoU-Aware Quality Alignment (IQA)} to bridge the disparity between independent coordinate parameter regression and true oriented bounding box overlap. In standard anchor-free detectors, box regression optimizes disjoint Smooth-L1 losses independently over spatial center $(x, y)$, footprint $(w, l)$, and heading angle $\psi$. However, independent parameter errors do not correlate monotonically with the actual Intersection-over-Union (IoU) overlap of rotated bounding boxes. Furthermore, standard classification confidence scores fail to reflect spatial localization precision, severely degrading candidate ranking during rotated Non-Maximum Suppression (NMS).

\paragraph{Oriented Geometric Alignment (OGA).}
For every cell $(u, v)$ where $\mathbf{M}_{\mathrm{reg}} = 1$, predicted and ground-truth boxes are decoded into four 2D corners $\{\widehat{\mathbf{c}}_m\}_{m=1}^4$ and $\{\mathbf{c}_m^*\}_{m=1}^4$. OGA couples two synergistic geometric objectives:
1. \textit{Multi-Axis Projection GIoU ($\ell_{\mathrm{proj}}$)}: Projected bounding box overlap is evaluated following Marginalized Generalized IoU~\cite{le2026mgiou} across four unit normal projection axes defining the prediction and ground-truth rectangles:
\begin{equation}
    \mathbf{n}_k \in \left\{ \mathbf{n}_{\mathrm{len}}^{\mathrm{pred}}, \mathbf{n}_{\mathrm{wid}}^{\mathrm{pred}}, \mathbf{n}_{\mathrm{len}}^{\mathrm{gt}}, \mathbf{n}_{\mathrm{wid}}^{\mathrm{gt}} \right\}.
    \label{eq:projection_axes}
\end{equation}
For each axis $\mathbf{n}_k$, 1D intervals of intersection length $I_k$, union length $U_k$, and smallest enclosing hull $E_k$ are determined, yielding 1D GIoU~\cite{rezatofighi2019giou}:
\begin{equation}
    \begin{aligned}
        g_k &= \frac{I_k}{U_k} - \frac{E_k - U_k}{E_k}, \\
        \bar{g} &= \frac{1}{4}\sum_{k=1}^4 g_k, \qquad
        \ell_{\mathrm{proj}} = \frac{1 - \bar{g}}{2}.
    \end{aligned}
    \label{eq:mgiou_loss}
\end{equation}
\par\noindent{\raggedright\textit{2. Scale-Normalized $\pi$-Symmetric Corner Distance ($\ell_{\mathrm{corner}}$)}:\par}\noindent
To ensure accurate vertex localization under doubled-angle symmetry, we evaluate the minimum L1 distance across direct and $\pi$-permuted corner correspondences:
\begin{equation}
    \ell_{\mathrm{corner}} = \frac{\min\left\{
        \begin{array}{l}
            \displaystyle\sum_{m=1}^4 \|\widehat{\mathbf{c}}_m - \mathbf{c}_m^*\|_1, \\
            \displaystyle\sum_{m=1}^4 \|\widehat{\mathbf{c}}_m - \mathbf{c}_{5-m}^*\|_1
        \end{array}
    \right.}{4\max\left(\sqrt{(w^*)^2 + (l^*)^2}, 10^{-6}\right)}.
    \label{eq:corner_loss}
\end{equation}
Normalizing by the target bounding box diagonal ensures scale invariance across categories. The composite geometric loss is $\mathcal{L}_{\mathrm{geo}} = \ell_{\mathrm{proj}} + \beta_{\mathrm{corner}} \ell_{\mathrm{corner}}$ with $\beta_{\mathrm{corner}} = 1.0$.

\paragraph{IoU-Aware Quality Alignment (IQA).}
The quality head predicts continuous overlap score $\hat{q} = \sigma(\hat{Z}_{\mathrm{qual}}) \in [0, 1]$. It is supervised via Binary Cross-Entropy (BCE) using the detached MGIoU similarity as the ground-truth target:
\begin{equation}
    q^* = \operatorname{stopgrad}(\operatorname{clip}(\bar{g}, 0, 1)), \qquad \mathcal{L}_{\mathrm{qual}} = \operatorname{BCE}(\hat{q}, q^*).
    \label{eq:iqa_loss}
\end{equation}
Detaching the target prevents gradient instability while forcing the model to learn reliable confidence calibration.

\paragraph{Temperature-Softmax Bounded Uncertainty Weighting (T-SBUW).}
To dynamically harmonize multi-task gradient scales across six heterogeneous loss objectives $\mathcal{T} = \{\mathrm{cls}, \mathrm{off}, \mathrm{size}, \mathrm{yaw}, \mathrm{geo}, \mathrm{qual}\}$ ($J=6$), we formulate \textbf{T-SBUW} as a principled, bounded optimization framework that eliminates fragile manual hyperparameter tuning. The formulation operates via two coupled mechanisms:
1. \textit{Bounded Softmax Weights}: Learnable logit parameters $a_k$ are soft-clamped via hyperbolic tangent with bound $b_{\mathrm{uw}} = 3.0$, and converted to positive normalized weights via temperature-controlled softmax ($\tau_{\mathrm{uw}} = 2.0$):
\begin{equation}
    \begin{aligned}
        \bar{a}_k &= b_{\mathrm{uw}} \tanh(a_k / b_{\mathrm{uw}}), \\
        Z_{\mathrm{uw}} &= \sum_{j \in \mathcal{T}} \exp(\bar{a}_j / \tau_{\mathrm{uw}}), \\
        \omega_k &= J \cdot \frac{\exp(\bar{a}_k / \tau_{\mathrm{uw}})}{Z_{\mathrm{uw}}}, \\
        \sum_{k \in \mathcal{T}} \omega_k &= J.
    \end{aligned}
    \label{eq:tsbuw_weights}
\end{equation}
This construction strictly conserves the total weight.
2. \textit{Running Scale Calibration}: Exponential Moving Average (EMA) with momentum $\beta_{\mathrm{EMA}} = 0.99$ tracks the unweighted running loss magnitude $\mu_k \leftarrow 0.99\mu_k + 0.01\mathcal{L}_k$. The balanced objective for group $g$ is:
\begin{equation}
    \mathcal{L}_g = \left(\frac{1}{J}\sum_{k \in \mathcal{T}} \mu_k\right) \sum_{k \in \mathcal{T}} \omega_k \frac{\mathcal{L}_k}{\max(\mu_k, 10^{-4})}.
    \label{eq:balanced_loss}
\end{equation}
The total network objective is $\mathcal{L}_{\mathrm{total}} = 0.5\mathcal{L}_1 + 0.5\mathcal{L}_2$. The twelve logit parameters are utilized strictly during training and discarded at inference.


\subsection{Coordinate Decoding and Inference Pipeline}
\label{sec:decoding_and_pipeline}

\noindent
\captionof{algorithm}{End-to-end MobilePIXORNeXt inference and box decoding pipeline.}
\label{alg:inference_pipeline}
\vspace{2pt}
{\small
\noindent\textbf{Require:} Raw LiDAR point cloud $\mathcal{P} = \{(x_i, y_i, z_i, \iota_i)\}_{i=1}^N$, ROI bounds $[x_{\min}, x_{\max}] \times [y_{\min}, y_{\max}] \times [z_{\min}, z_{\max}]$\par
\noindent\textbf{Require:} Score threshold $\tau_{\mathrm{score}} = 0.05$, Rotated NMS threshold $\tau_{\mathrm{nms}} = 0.10$, quality exponent $\alpha = 0.5$\par
\noindent\textbf{Ensure:} Final decoded 3D oriented bounding boxes $\mathcal{B} = \{(c_k, s_k, \hat{x}_k, \hat{y}_k, \hat{l}_k, \hat{w}_k, \hat{\psi}_k)\}_{k=1}^M$\par
\begin{enumerate}
    \setlength{\topsep}{2pt}
    \setlength{\itemsep}{0pt}
    \setlength{\parsep}{0pt}
    \renewcommand{\labelenumi}{\textbf{\arabic{enumi}:}}
    \item Filter raw points $\mathcal{P}$ within inward margin $\epsilon = 0.001$\,m of spatial ROI.
    \item Deterministically rasterize points into 14-channel Strata-BEV14 tensor $\mathbf{X} \in \mathbb{R}^{14 \times 800 \times 704}$ via Eq.~(\ref{eq:density_encoding})--(\ref{eq:offset_encoding}).
    \item Forward $\mathbf{X}$ through ConvNeXt stem to obtain stride-2 feature $\mathbf{F}^{(2)} \in \mathbb{R}^{32 \times 400 \times 352}$.
    \item Extract multi-scale features through Stages 2, 3, 4 via MobilePixorNeXt-S blocks to obtain $\mathbf{F}^{(4)}, \mathbf{F}^{(8)}, \mathbf{F}^{(16)}$.
    \item Fuse multi-scale features via Top-Down SG-FPN Neck into shared map $\mathbf{F}_{\mathrm{out}} \in \mathbb{R}^{32 \times 200 \times 176}$.
    \item Evaluate Grouped Prediction Towers for Car ($g=1$) and Pedestrian/Cyclist ($g=2$), yielding classification maps $\mathbf{P}_{\mathrm{cls}}$, subcell offsets $\widehat{\mathbf{o}}$, log-sizes $\widehat{\mathbf{d}}$, doubled yaws $\widehat{\mathbf{a}}$, and quality $\widehat{\mathbf{q}}$.
    \item \textbf{for each} class $c \in \{\text{Car}, \text{Pedestrian}, \text{Cyclist}\}$ \textbf{do}
    \item \quad Identify local $3 \times 3$ candidate peaks on classification heatmap $\mathbf{P}_{\mathrm{cls}, c}$.
    \item \quad Compute IoU-aware composite ranking score: $s_{\mathrm{det}} = (\mathbf{P}_{\mathrm{cls}, c})^{1 - \alpha} \cdot (\widehat{\mathbf{q}})^\alpha$.
    \item \quad Filter candidate cells satisfying $\mathbf{P}_{\mathrm{cls}, c} > \tau_{\mathrm{score}}$ and $s_{\mathrm{det}} > \tau_{\mathrm{score}}$.
    \item \quad Decode metric coordinates, dimensions, and heading angles via Eq.~(\ref{eq:box_decode}).
    \item \quad Apply Classwise Rotated Non-Maximum Suppression with IoU threshold $\tau_{\mathrm{nms}}$.
    \item \textbf{end for}
    \item \textbf{return} Final detection set $\mathcal{B}$ sorted in descending order of composite score $s_{\mathrm{det}}$.
\end{enumerate}
}

\par\vspace{0.5\baselineskip}


The complete inference procedure is formalized in Algorithm~\ref{alg:inference_pipeline}. For each candidate cell $(u, v)$ where predicted classification probability $p_{\mathrm{cls}} > \tau_{\mathrm{score}} = 0.05$ forms a $3 \times 3$ local spatial peak, metric continuous bounding boxes are decoded via:
\begin{align}
    \hat{x} &= x_{\min} + u s_{\mathrm{out}}\Delta_x + \hat{o}_x, \nonumber\\
    \hat{y} &= y_{\min} + v s_{\mathrm{out}}\Delta_y + \hat{o}_y, \nonumber\\
    \hat{w} &= \exp(\hat{d}_1), \qquad \hat{l} = \exp(\hat{d}_2), \nonumber\\
    \hat{\psi} &= \frac{1}{2}\operatorname{atan2}(\hat{a}_2, \hat{a}_1).
    \label{eq:box_decode}
\end{align}
Predicted orientation angle $\hat{\psi} \in [-\pi/2, \pi/2]$ is fully recovered without trigonometric ambiguity.

To align classification confidence with geometric overlap precision, detection candidates are ranked via a joint IoU-aware composite confidence score:
\begin{equation}
    s_{\mathrm{det}} = (p_{\mathrm{cls}})^{1 - \alpha_{\mathrm{score}}} \cdot (\hat{q})^{\alpha_{\mathrm{score}}}, \qquad \alpha_{\mathrm{score}} = 0.5.
    \label{eq:joint_score}
\end{equation}
Candidates with $s_{\mathrm{det}} > 0.05$ undergo class-wise rotated NMS at IoU threshold $\tau_{\mathrm{nms}} = 0.10$. The output is capped at 500 boxes per scan.

\paragraph{Parameter Distribution Breakdown.}
The complete MobilePIXORNeXt detector contains exactly \textbf{753,569 trainable parameters} ($< 0.76$\,M), corresponding to an ultra-compact FP32 checkpoint size of $9.34$\,MB:
\begin{itemize}
    \item \textbf{Backbone Body}: $604,864$ parameters ($80.3\%$).
    \item \textbf{Scale-Gated Neck (SG-FPN)}: $36,784$ parameters ($4.9\%$).
    \item \textbf{Grouped Prediction Heads}: $111,921$ parameters ($14.8\%$), divided into $55,944$ parameters for Group \texttt{car} and $55,977$ parameters for Group \texttt{ped\_cyc}.
    \item \textbf{Training-Only T-SBUW Logits}: 12 parameters ($< 0.01\%$), eliminated during deployment.
\end{itemize}
This compact footprint enables full end-to-end inference at $16.41$\,FPS ($60.96$\,ms) and network forward throughput of $55.94$\,FPS ($17.88$\,ms) on commodity NVIDIA Tesla T4 GPUs.
